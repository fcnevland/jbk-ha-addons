# JBK add-ons voor Home Assistant

Add-ons van Johnny Bos Keukens.

- **JBK Bestelrobot** – plaatst bestellingen die in het JBK-dashboard akkoord zijn gegeven bij de webshop van de leverancier (eerst de Quooker-dealerwebshop). Zie `jbk_bestelrobot/DOCS.md`.

Toevoegen in Home Assistant: Instellingen → Add-ons → Add-on-winkel → ⋮ → Repositories → `https://github.com/fcnevland/jbk-ha-addons`.

Deze repository bevat geen wachtwoorden of sleutels; die worden in Home Assistant zelf ingevuld.
